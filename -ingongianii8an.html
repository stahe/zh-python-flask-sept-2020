    25. 应用练习：第8版

    25.1. 简介

    我们将编写一个新的客户端/服务器应用程序。该服务器的创新之处在于它将管理一个会话。我们将税务管理数据放入作用域为 [application] 的对象中，而是放入作用域为 [session] 的对象中。这样做会导致代码性能下降。 当一个对象可被所有用户以只读方式共享时，将其设为作用域为 [application] 的对象，比设为作用域为 [session] 的对象更为合适。 这样至少可以节省带宽，因为会减少会话 Cookie 的大小。但我们希望展示一个客户端/服务器应用程序，其中客户端和服务器之间会交换会话 Cookie。

    25.3.1.1. 类 [ImpôtsDaoWithHttpSession]

    [dao] 层由以下 [ImpôtsDaoWithHttpSession] 类实现：

    
# 导入

import requests
from flask_api import status
from myutils import decode_flask_session

from AbstractImpôtsDao import AbstractImpôtsDao
from AdminData import AdminData
from ImpôtsError import ImpôtsError
from InterfaceImpôtsMétier import InterfaceImpôtsMétier
from TaxPayer import TaxPayer


class ImpôtsDaoWithHttpSession(AbstractImpôtsDao, InterfaceImpôtsMétier):

    # 构造函数
    def __init__(self, config: dict):
        # 父级初始化
        AbstractImpôtsDao.__init__(self, config)
        # 保存配置项
        # 通用配置
        self.__config = config
        # 服务器
        self.__config_server = config["server"]
        # 调试模式
        self.__debug = config["debug"]
        # 日志记录器
        self.__logger = None
        # Cookie
        self.__cookies = None

    # 未使用的方法
    def get_admindata(self) -> AdminData:
        pass

    # 税额计算
    def calculate_tax(self, taxpayer: TaxPayer, admindata: AdminData = None):
        # 允许异常上报
        # GET 参数
        params = {"marié": taxpayer.marié, "enfants": taxpayer.enfants, "salaire": taxpayer.salaire}
        # 使用 Basic 认证登录？
        if self.__config_server['authBasic']:
            response = requests.get(
                # 被查询服务器的 URL
                self.__config_server['urlServer'],
                # URL 的参数
                params=params,
                # Basic 身份验证
                auth=(
                    self.__config_server["user"]["login"],
                    self.__config_server["user"]["password"]),
                cookies=self.__cookies)

        else:
            # 不使用 Basic 身份验证的连接
            response = requests.get(self.__config_server['urlServer'], params=params, cookies=self.__cookies)
        # 如果响应中包含 Cookie，则获取它们
        if response.cookies:
            self.__cookies = response.cookies
            # 获取会话 Cookie
            session_cookie = response.cookies.get('session')
            # 对其进行解码以完成登录
            if session_cookie:
                # 登录器
                if not self.__logger:
                    self.__logger = self.__config['logger']
                # 进行日志记录
                self.__logger.write(f"cookie de session={decode_flask_session(session_cookie)}\n")

        # 调试模式？
        if self.__debug:
            # 日志记录器
            if not self.__logger:
                self.__logger = self.__config['logger']
            # 正在记录日志
            self.__logger.write(f"{response.text}\n")
        # 响应状态码 HTTP
        status_code = response.status_code
        # 将响应 jSON 放入字典
        résultat = response.json()
        # 如果状态码不为 200，则报错 OK
        if status_code != status.HTTP_200_OK:
            # 已知错误已关联至响应中的键 [erreurs]
            raise ImpôtsError(87, résultat['réponse']['erreurs'])
        # 已知该结果与响应中的键 [result] 相关联
        # 使用该结果修改输入参数
        taxpayer.fromdict(résultat["réponse"]["result"])
    • 第 30 行：[dao] 层将管理一个 Cookie 字典；
    • 第 58 行：属性 [response.cookies] 是一个字典，用于收集服务器在 HTTP 和 [Set-Cookie] 头部中发送的 Cookie；
    • 第 59 行：这些 Cookie 存储在 [dao] 层中。当同一客户端后续发出请求时，它们将被发回给服务器；
    • 第60-68行：尽管并非必需，但我们仍会获取会话Cookie。在服务器发送的Cookie字典中，会话Cookie与键[session]相关联；
    • 第 62-68 行：解码会话 Cookie 以完成登录；
    • 第 68 行：我们稍后将详细介绍用于解码会话 Cookie 的函数 [decode_flask_session]；
    • 第 52 行和第 57 行：每次来自同一客户端的请求，服务器都会将发送的 Cookie 发回给该客户端。正是通过这种方式，客户端与服务器之间的 Flask 会话得以维持；

    现在需要记住的是，[dao] 层将由多个线程同时执行。因此，必须检查类实例的所有属性，并确认对这些属性的并发访问是否会引发问题。 在此我们添加了 [self.__cookies] 属性（第 30 行）。该属性在第 59 行被修改。因此，所有线程都在对同一共享数据进行写入操作。但这种访问方式会引发问题：代表特定客户端的每个线程都有其专属的会话 Cookie。 实际上，其中包含每个客户（即线程）的唯一客户编号。如果不采取任何措施，线程 T2 可能会覆盖线程 T1 的 Cookie。

    我们之前已经见过一种解决此问题的方法：可以在作为构造函数参数传递的文件 [config]（第 17 行）中，为每个线程创建不同的键。例如，可以使用线程名称作为键：

    • 第 59 行，可以这样写： 
    
config[thread_name][‘cookies’]=cookies
    • 第 52 行，则可写为： 
    
cookies=config[thread_name][‘cookies’]

    这里我们将采用一种不同的技术：每个线程（=客户端）将拥有自己的 [dao] 层。这样第 59 行就不再有问题，因为此时使用的 Cookie 属于单一客户端。

    为此，我们将创建一个新的类 [ImpôtsDaoWithHttpSessionFactory]。

    25.3.1.2. Flask会话解码函数

    函数 [decode_flask_session] 在脚本 [myutils] 中定义：

    我们之前已经学习过 |myutils| 脚本。该脚本是一个机器作用域模块，本课程中的各个脚本均可通过以下语句将其导入：

    其中，[decode_flask_session] 函数的定义如下：

    
def decode_flask_session(cookie: str) -> str:
    # 来源：https://www.kirsle.net/wizards/flask-session.cgi
    compressed = False
    payload = cookie

    if payload.startswith('.'):
        compressed = True
        payload = payload[1:]

    data = payload.split(".")[0]

    data = base64_decode(data)
    if compressed:
        data = zlib.decompress(data)

    return data.decode("utf-8")
    • 第2行：URL，我就是在那里找到这个功能的；

    • 第3-16行：对于这段我不熟悉的代码，我将不予评论；

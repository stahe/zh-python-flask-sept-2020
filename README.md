# Python 3 和 Flask 框架入门

🔗 **查看在线文档：** [https://stahe.github.io/zh-python-flask-sept-2020/](https://stahe.github.io/zh-python-flask-sept-2020/)

## 📝 目录

本项目提供了一系列涵盖多种主题的 Python 脚本：
* 语言基础。
* MySQL 和 PostgreSQL 数据库管理。
* TCP/IP 网络编程（HTTP、POP3、IMAP、SMTP 协议）。
* 使用 Flask 框架进行 MVC Web 编程。
* 三层架构与基于接口的编程。

## 🎯 目标受众

本示例集面向：
* 已有脚本语言（Perl、PHP、VBScript）使用经验的开发者。
* 熟悉类型化语言（Java、C#）并希望探索面向对象脚本语言的开发者。

> ⚠️ **注意：** 本文档不适合编程经验较少或完全没有编程经验的读者。

## 💡 理念

本项目既不是完整的课程，也不是“最佳实践”的合集。其目的是提供具体的示例，帮助您迈出使用 Python 3 和 Flask 的第一步。代码按原样提供，部分脚本可能尚有优化空间。

为充分利用本内容，需要进行**主动阅读**：您需要分析代码、阅读相关注释并观察运行结果。

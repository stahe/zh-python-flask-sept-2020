    本文提供了一份涵盖不同领域的 Python 脚本列表：

    • 语言基础；
    • 数据库管理 MySQL 和 PostgreSQL；
    • 网络编程 TCP/ IP（协议 HTTP、POP3、IMAP、SMTP）；
    • 基于 FLASK 框架的 MVC 网页编程；
    • 三层架构与接口编程；

    这不是一门全面的 Python 课程，而是一本面向已使用过 Perl、PHP 等脚本语言的开发者的示例集， VBScript，或习惯于Java、C#等强类型语言，并希望探索面向对象脚本语言的开发者。对于从未或很少接触编程的读者，本文档并不适用。

    本文档亦非“最佳实践”汇编。经验丰富的开发者可能会发现某些代码尚有优化空间。本文档的唯一目的是为希望入门 Python 3 语言和 Flask 框架的读者提供示例。读者随后可通过其他文档进一步深化学习。

    脚本均附有注释，并附有执行结果。有时还会提供额外的说明。阅读本文需主动思考：要理解一个脚本，必须同时阅读其代码、注释和执行结果。

    该文档是对 2011 年 6 月发布的一份旧文档 |https://tahe.developpez.com/tutoriels-cours/python/| 的更新。2011 年的文档是基于 Python 2.7 解释器构建的。 此后，Python 版本已更新至 3.x。 截至2020年2月，版本号已更新至3.8。3.x版本导致了不同版本间兼容性的断层：在Python 2.7下可运行的代码在Python 3.x下可能无法使用。控制台输出功能尤其如此。 在 2.7 版本中可以编写 [print "toto"]，而在 3.x 版本中则必须编写 [print("toto")]：需要添加括号。 这一简单变化导致2011年文档中提供的代码大多无法直接在Python 3.x中使用，必须进行修改。

    本新版文档不仅更新了2011年的代码使其可在Python 3.8中运行：

    • 关于TCP-IP编程和数据库使用的章节已发生重大变化；
    • 原先仅作为入门介绍的Web编程章节，现已发展为使用FLASK框架的完整课程；

    在构建本课程时，我采取了一种非传统的做法：我将 PHP [Introduction au langage PHP7 par l’exemple] 课程进行了移植。因此，我并未遵循传统的 Python 或 Flask 课程结构。 我首要的目标是探索如何利用 Python 3 实现我在 PHP 7 中完成的功能。最终，我成功地使用 Python 3 / Flask 重现了 PHP 7 课程中的所有示例。

    • 唯一的修改是第23行：现在发送响应XML；

    函数 [xml_response] 在模块 [myutils] 中定义：

    
import xmltodict
…
def xml_response(résultat: dict, status_code: int) -> tuple:
    # 结果：待转换为字符串的字典XML
    xmlString = xmltodict.unparse(résultat)
    # 返回响应 HTTP
    response = make_response(xmlString)
    response.headers['Content-Type'] = 'application/xml; charset=utf-8'
    return response, status_code
    • 第3行：函数[xml_response]接收的参数为：
      • 待转换为 XML 的字典 [résultat]；
      • 要返回给 Web 客户端的状态代码 [status_code]；
    • 第5行：使用库[xmltodict]生成字符串XML；
    • 第 8 行：使用标头 [Content-Type] 告知客户端正在向其发送 XML；

    函数 [xml_response] 必须导入到脚本 [__init__.py] 中：

    
from .myutils import set_syspath, json_response, decode_flask_session, xml_response

    随后，需将模块 [myutils] 集成到机器范围的模块中。此操作需在终端 PyCharm 中通过命令 [pip install .] 完成（位于 packages 文件夹内）。
